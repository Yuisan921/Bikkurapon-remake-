# Arduino Uno R3用・360度連続回転サーボ対応版

PCアプリv2.3.0と組み合わせて使えます。管理画面の「実機を1回動かす」を
待機中にも受け取り、サーボへの動作指示後にPCへ完了通知を返します。
通常のコイン投入にも対応しています。

今回は両方のホッパーを連続回転サーボとして設定しています。一般的な180度の
SG90を使う側は、スケッチ先頭の `SERVO_A_CONTINUOUS` または
`SERVO_B_CONTINUOUS` を `false` に変更してください。

## 書き込み方

1. ZIPを右クリックして「すべて展開」します。
   サーボの外部電源は、書き込みが完了するまで切っておきます。
2. Ctrl + Shift + Escでタスクマネージャーを開き、
   残っている `bikkurapon.exe` を終了します。画面を閉じるだけでは残る場合があります。
3. このフォルダの `arduino_uno_usb_serial.ino` をArduino IDEで開きます。
4. ボードを「Arduino Uno」、ポートを接続したUnoのCOM番号にします。
5. シリアルモニター・シリアルプロッターを閉じてから、右矢印の「書き込み」を押します。
6. 書き込み完了後にびっくらぽんを起動し、接続済みになってから3秒ほど待ちます。
7. サーボの外部電源を入れ、待機中に停止していることを確認します。
8. 管理画面で「実機を1回動かす」を押します。約0.3秒回転して停止する設定です。

「COM3を開けない」等のエラーが残る場合は、USBを抜き差しし、ポートを選び直します。

## 配線と動作

- 当たり用サーボの信号線：D9
- はずれ用サーボの信号線：D10
- 赤外線センサーのOUT：D2（検知時LOW）
- サーボ電源：外部5V。外部電源のマイナスとArduinoのGNDを共通にします。
- 連続回転サーボ：起動時は停止信号1500µs。抽選時だけ1600µsで0.3秒回し、停止信号に戻します。
- 通常の角度指定サーボ（CONTINUOUS=false）：0度 → 90度で1秒保持 → 0度。

## 停止・回転時間の調整

連続回転サーボの停止位置は個体差があります。待機中にゆっくり回る場合は、
その側の `SERVO_A_STOP_US` / `SERVO_B_STOP_US` を1500から5〜10ずつ
増減して停止する値を探し、その都度書き込み直してください。
停止信号でも速く回り続ける場合は電源を切り、製品の仕様や故障も確認してください。

`SERVO_A_RUN_MS` / `SERVO_B_RUN_MS` は回す時間（ミリ秒）、
`SERVO_A_RUN_US` / `SERVO_B_RUN_US` は速度と方向を決める信号です。
0.3秒は短い動作確認用の初期値で、1回転・カプセル1個の排出を保証しません。
本番のホッパーに取り付けた後で実際の排出量に合わせて調整してください。

完了通知はサーボへの指示を終えたことを示します。カプセルの実排出を検出する
センサーは使用していないため、テスト時には排出口も確認してください。
