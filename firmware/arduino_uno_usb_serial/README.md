# Arduino Uno R3用・360度連続回転サーボ対応版

PCアプリv2.7.0と組み合わせて使います。LEDとCdSの間をコインが通って光を遮ると
抽選を開始します。抽選の演出（動画）が終わってから届く
排出命令を受け取り、サーボへの動作指示後にPCへ完了通知を返します。
通常のコイン投入にも対応しています。

今回は両方のホッパーを連続回転サーボとして設定しています。一般的な180度の
SG90を使う側は、スケッチ先頭の `SERVO_A_CONTINUOUS` または
`SERVO_B_CONTINUOUS` を `false` に変更してください。

## 書き込み方

1. ZIPを右クリックして「すべて展開」します。
   サーボの外部電源は、書き込みが完了するまで切っておきます。
2. Ctrl + Shift + Escでタスクマネージャーを開き、
   残っている `bikkurapon.exe` を終了します。画面を閉じるだけでは残る場合があります。
3. このフォルダの `arduino_uno_usb_serial.ino` をArduino IDEで開きます。
4. ボードを「Arduino Uno」、ポートを接続したUnoのCOM番号にします。
5. シリアルモニター・シリアルプロッターを閉じてから、右矢印の「書き込み」を押します。
6. 書き込み完了後にびっくらぽんを起動し、接続済みになってから3秒ほど待ちます。
7. コイン通路を空にしたまま起動し、LEDが点灯してから1秒ほど待ちます。
   サーボの外部電源を入れ、待機中に停止していることも確認します。
8. 管理画面で「実機を1回動かす」を押します。演出終了後、約0.77秒回転して停止します。

「COM3を開けない」等のエラーが残る場合は、USBを抜き差しし、ポートを選び直します。

## 配線と動作

- 当たり用サーボの信号線：D9
- はずれ用サーボの信号線：D10
- LED：D4 → 220〜330Ω抵抗 → LEDの長い脚、LEDの短い脚 → GND
- CdS分圧：5V → CdS → A0 → 10kΩ抵抗 → GND
- サーボ電源：外部5V。外部電源のマイナスとArduinoのGNDを共通にします。
- 連続回転サーボ：起動時は停止信号1500µs。演出終了後、1600µsで指定時間だけ回し、停止信号に戻します。
- 通常の角度指定サーボ（CONTINUOUS=false）：0度 → 90度で1秒保持 → 0度。

## LED・CdSコインセンサー

LEDとCdSをコイン通路の両側で正面に向けます。コインが通ったときに光が完全に
遮られる位置へ固定し、黒いストローや熱収縮チューブで覆うと周囲光の影響を減らせます。
CdSに極性はありません。LEDには必ず220〜330Ωの抵抗を直列に入れてください。

起動時、LEDが直接当たっている状態のA0値を32回測定して自動的に基準を作ります。
そのため起動後約0.6秒は通路を空にしてください。待機中は基準値をゆっくり追従させ、
LEDや周囲光の小さな変動を吸収します。20ミリ秒以上暗くなったときだけコインとして
受け付け、光が150ミリ秒戻るまで次のコインを受け付けません。

誤反応する場合は `CDS_BLOCK_DROP_PERCENT` を25から30〜40へ上げます。
反応しにくい場合は20程度へ下げます。A0の明るい値が150未満の場合は、
LEDの向き、CdSの分圧、10kΩ抵抗を確認してください。

以前のD2赤外線センサーへ戻す場合は、
`COIN_SENSOR_USE_CDS`を`false`に変更できます。

## 管理画面からの手動位置調整

管理画面の当たり側・はずれ側ボタンを押している間だけ、該当サーボを回します。
ボタンを離すと停止します。ブラウザーやUSB通信の異常で停止命令が届かなくても、
PCからの継続信号が2秒間途切れるとArduino自身が両方のサーボを停止します。
手動調整中はCdSを遮ってもコインとして受け付けません。

## 停止・回転時間の調整

連続回転サーボの停止位置は個体差があります。待機中にゆっくり回る場合は、
その側の `SERVO_A_STOP_US` / `SERVO_B_STOP_US` を1500から5〜10ずつ
増減して停止する値を探し、その都度書き込み直してください。
停止信号でも速く回り続ける場合は電源を切り、製品の仕様や故障も確認してください。

PCの管理画面の「半回転（約180度）の調整」で回す時間（50〜2000ミリ秒）を保存できます。
初期値は770ミリ秒です。0.3秒で約70度という実測から、300×180÷70で計算しました。
実際に160度回った場合は現在の時間×180÷160へ、200度回った場合は×180÷200へ調整します。
負荷や電源によって変動するため、180度を正確に保証する制御ではありません。

`SERVO_A_RUN_US` / `SERVO_B_RUN_US` は速度と方向を決める信号です。
`SERVO_A_RUN_MS` / `SERVO_B_RUN_MS` は旧PCアプリから時間指定なしで届いた場合の値です。

完了通知はサーボへの指示を終えたことを示します。カプセルの実排出を検出する
センサーは使用していないため、テスト時には排出口も確認してください。

ゲーム画面を閉じた場合や動画が止まった場合は、最大5分待っても演出終了が届かなければ、
排出せず在庫予約を取り消し、管理画面にエラーを表示します。
